What Is Upside Down Text?

Upside down text uses special Unicode characters that visually resemble flipped versions of regular letters. For example, the letter "a" becomes "ɐ", "b" becomes "q", "h" becomes "ɥ", and so on. When the text is also reversed in order, reading it from right to left while tilting your head gives the original text — creating a fun visual effect.

Because these are real Unicode characters, the upside down text can be copied and pasted anywhere that supports regular text — social media posts, bios, usernames, messages, and more.

How to Use the Upside Down Text Generator

  1. Type or paste your text into the input box. The flipped output appears live.
  2. Choose a flip mode — "Flip + Reverse" flips each letter and reverses the whole text order (classic upside down effect). "Flip Only" flips each letter but keeps the order the same.
  3. Copy the output and paste it wherever you want.

Flip + Reverse vs Flip Only

Flip + Reverse is the classic upside down text effect. It flips every letter upside down AND reverses the order of the entire text. If you physically flip your screen or tilt your head 180 degrees, the text reads normally. This is the most commonly used mode for social media tricks.

Flip Only flips each letter individually without reversing the order. The result reads left-to-right like normal text but each character looks flipped — a different stylistic effect.
