What Are Small Caps?

Small caps are a typographic style where lowercase letters are replaced with uppercase letters that are smaller than the standard capital letters — similar in height to regular lowercase letters. In traditional typography, small caps are a font feature. This tool generates small caps using Unicode characters, which means the output can be pasted and displayed anywhere that supports Unicode text — including social media bios, Twitter, Instagram, Discord, WhatsApp, and more.

How to Use the Small Caps Generator

  2. Copy the output using the Copy button.
  3. Paste it anywhere — social media profiles, bios, messages, documents, or anywhere that supports text.
